# Backend par les Premiers Principes

Adaptation française enrichie de **[Backend from First Principles](https://github.com/DsThakurRawat/Backend-from-first-Principle)** de [@DsThakurRawat](https://github.com/DsThakurRawat).

Une série de 24 chapitres sur l'ingénierie backend, des fondamentaux HTTP aux WebSockets, en passant par les bases de données, le cache, Kafka et le déploiement en production.

## Ce que cette version ajoute à l'originale

- Traduction française intégrale, termes techniques usuels conservés en anglais avec tooltips de définition
- Exercices de fin de chapitre (réponses visibles après validation)
- Un angle sécurité par chapitre
- Exemples de code TypeScript en plus du Go et du Python
- Glossaire
